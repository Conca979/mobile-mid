🏛️ Android Architecture Stack & Compilation (Lec 3) ▼

4 Layers from Bottom to Top:

  1. Linux Kernel (C): Hardware drivers, process isolation, power management.
  2. Libraries (C/C++) & Android Runtime: SQLite, WebKit, FreeType, Media Framework + Dalvik/ART virtual machine.
  3. Application Framework (Java): ActivityManager, WindowManager, NotificationManager, LocationManager.
  4. Applications (Java): Home, Contacts, Phone, Browser, USTH Weather.

Compilation Toolchain: .java → javac → .class → dx tool → .dex → packaged into .apk.

Dalvik vs ART: Dalvik uses JIT (Just-In-Time) compilation. ART uses AOT (Ahead-Of-Time) compilation during installation.

🔄 Activity Lifecycle & Screen Rotation (Lec 3) ▼

Lifecycle Methods:

  • onCreate(): Initialize activity, call setContentView(), findViewById().
  • onStart(): Activity becoming visible.
  • onResume(): In foreground, acquire exclusive resources (e.g. Camera).
  • onPause(): Losing focus, release camera (mCamera.release()), save data. *Always call super.onPause() first!*
  • onStop(): No longer visible.
  • onDestroy(): Finishing (after calling finish()) or killed by OS.

Device Rotation: Destroys and recreates the instance: onSaveInstanceState() → onDestroy() → onCreate() → onRestoreInstanceState().

🧩 Fragments & ViewPager (Lec 3 & 4) ▼

Fragment History: Officially native in Android 3.0 Honeycomb (API 11); supported down to Android 1.6 Donut (API 4) via Support Library.

ViewPager: Horizontal swiping tab container. Uses FragmentPagerAdapter. Connect to header using tabLayout.setupWithViewPager(pager).

Off-screen Limit: pager.setOffscreenPageLimit(3) keeps 3 pages alive on each side to prevent destroying/recreating.

🎨 9-Patch Drawables & Raw Data (Lec 4) ▼

9-Patch (*.9.png) Rules:

  • Top & Left Borders: Black pixels define the STRETCHABLE area.
  • Bottom & Right Borders: Black pixels define the PADDING / CONTENT area.

res/raw/ vs assets/:

  • res/raw/: Android resource, generates R.raw.id, opened with getResources().openRawResource(R.raw.xxx).
  • assets/: NOT a resource, no R ID, supports subdirectories, opened with getAssets().open("filename").
⚡ Threading Model & AsyncTask (Lec 5) ▼

Golden Rules:

  1. NEVER block the Main Thread (network, long disk I/O causes ANR).
  2. NEVER touch UI Views from worker threads → crashes with CalledFromWrongThreadException.

AsyncTask<Params, Progress, Result>:

  • onPreExecute(): Main Thread. Setup / show dialog.
  • doInBackground(): WORKER Thread. Required. Heavy task. Returns Result. Cannot touch UI!
  • onProgressUpdate(): Main Thread. Receives publishProgress().
  • onPostExecute(Result): Main Thread. Updates UI with result.
